# Code for identifying cross-loadings in BCFA with five regularization priors
Authors: Junhao Pan, Xinyu Qiao, Rongqian Sun, and Edward Hak-Sing Ip

Paper link: tbc

Contact: <sunrq@link.cuhk.edu.hk>

This directory provides a comparative evaluation of five regularization Priors for identifying cross-loading in Bayesian CFA via simulation.
